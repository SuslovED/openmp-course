# ДЗ3

Скопируйте сюда содержимое `homework/hw3-*/starter/` из материалов курса (оно заменит этот Makefile и `src/`),
затем следуйте тексту задания `homework/hw3-*/README.md`.

Порядок работы:
1. Прочитайте задание, заполните раздел «Прогноз» в `REPORT.md` и **закоммитьте** его: `git commit -m "ДЗ3: прогноз"`.
2. Реализуйте, добейтесь `make test` и `make tsan` без ошибок.
3. `make bench` → `results/*.csv`, `make plots` → `plots/*.png`. Закоммитьте и то и другое.
4. Допишите `REPORT.md` и `SOURCES.md`, удалите из обоих строку `template:unfilled`, сделайте push и убедитесь, что CI зелёный.
